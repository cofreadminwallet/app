## 1. 代币与资金流转架构

CofreAdmin 运行于**完全去中心化、直接流转且零平台托管的底层架构**之上，锚定于 Base 网络（Coinbase 孵化的以太坊 Layer 2）。所有流转资金绝对不经过任何开发者或中间资金池的托管：

```
[ 发送方用户 (客户端浏览器) ]
              │
              │ 1. 纯本地签名 EIP-3009 授权转账数据 (v, r, s)
              ▼
[ Relayer 调度中继器 / Paymaster ]
              │
              │ 2. 使用 Relayer 的 Gas 储备将原子交易提交至 Base 区块链
              ▼
┌─────────────────────────────────────────────────────────────┐
│ Base 网络官方 Circle USDC 智能合约:                         │
│ 部署地址: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913       │
│                                                             │
│ ├──> [99.8% 净额资金]          ──> 接收方钱包地址           │
│ ├──> [0.2% 协议微量手续费]     ──> 开发者国库金库钱包       │
│ └──> [Gas 成本报销划扣]        ──> Relayer 矿工费资金池     │
└─────────────────────────────────────────────────────────────┘
```

### 不可篡改的流转铁律：
1. **绝对零资金滞留风险：** 所有 USDC 转账均从付款方地址直接划拨至收款方地址。整个执行过程由 Circle 经公开审计的官方合约在单一区块中以原子化方式瞬间完成。
2. **矿工费全面抽象化 (零 ETH 门槛)：** 用户 100% 使用数字美元 (USDC) 结算。网络产生的微量手续费（通常低于 0.02 美元）通过 EIP-3009 签名授权，直接从转账金额的 USDC 零钱中扣减补偿给调度中继器，用户无需事先购买或兑换 ETH。
3. **自动化不可篡改分流：** 协议微额手续费（0.2%，最低扣除 0.05 美元）透明、自动汇入项目公开国库钱包，绝无任何人工干预或自由裁量空间。

## 3. 自主托管核心安全与全景隐私承诺

### A. 真正彻底的自主托管 (零服务器托管)
* **客户端本地派生：** 链上 EVM 钱包私钥完全在用户设备浏览器本地由 Web Crypto API 动态派生。
* **军工级信封加密静态存储：** 浏览器本地采用 **AES-GCM 256 位加密** 保护私钥，绑定设备独立密钥。
* **多代密码学敏捷演进机制 (`v1` → `v2` → `v3`)：**
  * *v1:* 基础格式派生，保持向后平滑兼容。
  * *v2:* 基于 PBKDF2 100,000 次强力迭代与 AES-GCM 信封加密体系。
  * *v3:* 基于 Web Crypto API 的不可导出密钥，隔离在受保护的 IndexedDB 专属安全硬件分区。
  * *1 键链上资产归集 (Sweep Balance):* 允许用户在不同代际密钥间一键发起全额链上归集划转。
* **数据主权自由可迁移：** 用户随时可通过生物识别或 PIN 鉴权后完整导出未加密明文私钥，自由导入至 MetaMask、Rabby、Rainbow 等任何主流钱包。

### B. 快速防窥隐私模式 (Shoulder Surfing Protection)
* 轻触顶部眼睛图标，首页 `HeroBalanceCard`、`DailyBudgetCard`、`RecentActivityCard` 以及 `ActiveVaultsPreview` 的敏感数值即刻全量转换为掩码遮蔽 (`••••••`)。
* 专为公共交通、咖啡馆与公共场合设计，彻底杜绝资产隐私被旁人偷窥。

## 4. 可持续商业模型与长效盈利机制

CofreAdmin 采用基于交易量和实际网络实用性的透明经济机制，实现长效稳健的现金流收益：

### A. 链上转账协议微额手续费 (0.2%)
* 用户在 Base 网络上发起的每笔转账或付款，系统将自动扣除透明的 **0.2% 协议微额手续费（最低扣除 0.05 美元）** 并直接划转至项目官方国库钱包 (`DEV_TREASURY_WALLET`)。
* **商业规模测算模型：**
  * **10,000 月活用户 (MAU)** 月均转账 200 美元（月交易总额 200 万美元） = **每月产生 4,000 美元** 自动化经常性收入。
  * **50,000 月活用户 (MAU)** 月均转账 200 美元（月交易总额 1,000 万美元） = **每月产生 20,000 美元** 自动化经常性收入。
  * **250,000 月活用户 (MAU)** 月均转账 350 美元（月交易总额 8,750 万美元） = **每月产生 175,000 美元** 自动化经常性收入。

### B. 法币入金与出金服务费率 (On/Off Ramp Spread)
* 深度接入全球各地受合规监管的法币出入金合作伙伴（如巴西 PIX、欧洲 SEPA、美国 ACH），在法币与 USDC 相互兑换时赚取 0.3% - 0.7% 的浮动流动性便利费率。

### C. 商业级商户收单与白标 API 解决方案
* 为全球跨境独立站电商、出海创作者提供基于 Base USDC 的即时无扣押收单组件与开发者 API 授权支持。

## 5. 全球合规审计与法务注销凭证标准

### A. 全球隐私合规 (GDPR, LGPD, CCPA)
* **零个人特权账户后门：** 100% 公开多租户架构，无任何特权账户或后门。
* **1 键彻底注销抹除：** 用户随时可发起一键注销，不可逆地物理粉碎云端数据库 (`userData`) 与设备本地沙盒的所有记录。
* **不可篡改合规审计凭据 (`legalAuditArchive`)：** 依据国际法规要求（如巴西 LGPD 第 16 条及欧洲 GDPR 第 17 条免责条款），系统在注销时生成匿名化加密时间戳存证，用于向监管机构出具依法合规彻底销毁数据的法务证明。
