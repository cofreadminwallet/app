## 1. 📲 应用安装指南 (PWA)

CofreAdmin 采用前沿的 **渐进式 Web 应用 (PWA)** 技术构建，无需受限于传统应用商店审核，即可享受与原生 App 媲美的顺畅交互与性能。

### 在 iPhone / iPad (iOS Safari) 上安装：
1. 在 **Safari** 浏览器中打开 CofreAdmin 访问链接。
2. 轻触屏幕底部的 **“分享”** 按钮（带有向上箭头的正方形图标）。
3. 向下滚动菜单并选择 **“添加到主屏幕”**。
4. 点击右上角的 **“添加”** 进行确认。
5. CofreAdmin 图标将出现在您的主屏幕上，启动时即为全屏原生体验，无任何浏览器网址栏干扰。

### 在 Android (Google Chrome) 上安装：
1. 在 **Google Chrome** 浏览器中打开 CofreAdmin 链接。
2. 轻触屏幕底部的提示横幅 **“安装应用”**，或点击右上角 **“三个点”** 菜单。
3. 选择 **“安装应用”**（或 *“添加到主屏幕”*）。
4. 确认安装后，应用将独立安装至设备，具备桌面快捷方式与离线高速缓存支持。

## 2. 🔑 账户访问与多平台统一认证

CofreAdmin 提供多样化登录体系，兼顾用户隐私保护与跨设备无缝数据同步：

* 🌐 **Google 账号登录：** 借助 Firebase 基础设施，在电脑端与移动端之间实现即时、可靠的云端加密同步。
* 🎮 **Discord 账号登录：** 专为 Web3 社区和游戏玩家设计的快捷一键登录方式。
* 🔄 **跨服务商已验证邮箱自动统一（v1.0.6 全新功能）：**
  * 当您使用相同的已验证邮箱分别通过 Google 或 Discord 登录时，CofreAdmin 会自动识别您的唯一合法身份。
  * 您的链上 Web3 钱包地址、账单流水、心愿金库与个人资料将自动保持统一，绝不产生重复账户、不再重复弹出条款确认，彻底杜绝数据覆盖风险。

* 🚪 **登出与切换账户：** 在 **“设置”** 选项卡中，轻触 **“退出登录”** 即可随时清除当前界面会话，同时安全保留本地与云端已加密数据。

## 3. 💵 Web3 数字钱包、汇率与快速隐私防窥模式

首次启动时，CofreAdmin 会为您派生一个 **100% 自主托管 (Self-Custodial)** 的以太坊虚拟机 (EVM) 钱包，原生运行于 **Base 网络（Coinbase 孵化的以太坊 Layer 2 扩容网络）**。

* **核心资产 (USDC)：** 您的账户余额以 **USD Coin (USDC)** 计价，与美元 1:1 挂钩，由全额现金与短期美国国债储备提供坚实支持。
* **实时外汇汇率换算：** 资产卡片同时展示 USDC 余额与实时本地法币估值（如 CNY / ¥、BRL / R$、EUR / € 等），数据由实时预言机动态更新。
* **👁️ 快速隐私防窥模式 (Shoulder Surfing Protection)：**
  * 在主余额卡片上轻触 **“眼睛图标”**，即可瞬间将敏感金额数字遮蔽为掩码 (`••••`)。
  * 隐私状态自动同步应用至主页所有组件（包括 **每日预算卡片**、**近期流水卡片** 以及 **进行中心愿金库预览**）。
  * 在地铁、咖啡厅或公共场合查看钱包时保护财务隐私，再次轻触即可恢复显示。
* **可用流动余额 vs. 金库锁定资金：**
  * **总资产：** 链上地址持有的所有 USDC 总额。
  * **金库专款：** 已存入特定储蓄目标的专款。
  * **可用自由余额：** 随时可用于日常消费与外部转账的流动资金。从此告别误花梦想储蓄金的烦恼！
* **网络随时切换：** 支持在 **Base 主网**（真实资产）与 **Base Sepolia 测试网**（模拟演练与教学）之间一键切换。

## 4. 📥 如何接收资金 (Base 网络 USDC)

无论是朋友转账、自由职业薪酬，还是从中心化交易所提现（如 Binance、Coinbase、OKX、Bybit、Kraken）：

1. 在首页或钱包卡片轻触 **“接收”** 按钮 📲。
2. 弹出窗口将展示您的 **官方收款二维码** 与 **Base 钱包地址** (`0x...`)。
3. **从其他钱包接收：** 让付款方直接扫描您的二维码。
4. **从中心化交易所提现充值：**
   * 点击 **“复制地址”**。
   * 在交易所提币页面中，选择提现币种为 **USDC**，且转账网络务必严格选择为 **Base**。*(注意：若误选以太坊主网或 Polygon 等网络，可能产生额外的检索成本或延迟)*。
5. **极速到账：** 仅需 2 至 3 秒，交易即可在 Base 区块链上完成终局确认，应用余额实时刷新。

## 5. 📤 如何发送付款、防剪贴板投毒与域名解析

向全球任何角落即时汇出数字美元，网络矿工费通常低于 **0.02 美元**：

1. 在首页轻触 **“发送”** 📤。
2. **指定接收地址：**
   * **Basenames (`.base.eth`) 与 ENS (`.eth`) 域名解析：** 无需死记冗长的十六进制地址，直接输入人类可读的 Web3 域名（例如 `alice.base.eth` 或 `vitalik.eth`）。系统内置防同形异义字 (Homograph) 欺诈校验。
   * **直接粘贴地址：** 支持任何合法的 EVM 十六进制地址 (`0x...`)。
   * **扫码识别：** 轻触相机图标直接扫描对方的钱包二维码。
3. **🛡️ 防剪贴板投毒高对比度视觉校验：**
   * 某些恶意剪贴板劫持程序会悄悄篡改复制的地址。
   * CofreAdmin 采用高对比度徽章显著标出地址的 **前 6 位** 与 **后 4 位** 字符，并附带防篡改校验标记。
   * 在签名确认前，请务必核对高亮首尾字符！
4. **⚠️ 首次收款人安全警示：**
   * 向此前从未发生过交互的新地址转账时，系统会自动弹出醒目的谨慎提示，防止误转手误。
5. **无需持有原生 ETH 支付 Gas：**
   * 依托智能账户抽象与 Circle Paymaster 赞助协议 (EIP-3009)，**您的钱包中无需储备 ETH**。极微小的网络手续费将直接从转账的 USDC 零头中扣除。
6. **身份鉴权与签名广播：**
   * 通过设备的生物识别（Face ID / 指纹识别）或 4 位安全 PIN 码一键确认转账。
7. **加密凭证与链上浏览器：**
   * 交易成功后即刻生成包含哈希值 (`TxHash`)、时间戳的电子凭单，并支持一键跳转 **BaseScan** 公开区块链浏览器核对。

## 10. 🛡️ 多层安全架构、PIN 键盘、生物识别与多代密码学升级

CofreAdmin 采用深度防御级别的密码学工程标准：

### 1. 拟真触感 4 位 PIN 键盘与 WebAuthn 生物识别
* 提供随机排列的拟真数字键盘，防止旁观者窥视按键轨迹。
* PIN 码采用 **设备硬件加盐的 SHA-256** 纯本地哈希处理，绝对不会离开您的设备。
* 开启 **WebAuthn 生物识别**（Face ID、指纹或 Windows Hello），实现安全顺畅的一键转账授权。

### 2. 多代密码学敏捷演进引擎 (`v1` → `v2` → `v3`)
* **v1 (兼容过渡代):** 基础派生格式，用于老旧环境与平滑过渡。
* **v2 (信封加密代):** 采用军用级 AES-GCM 256 位信封加密，结合 100,000 次迭代的 PBKDF2 强化派生。
* **v3 (硬件绑定代):** 基于 Web Crypto API 的不可导出非对称密钥，安全存储在受系统保护的 IndexedDB 分区中。
* **一键链上资产清扫 (Sweep Balance):** 支持跨代际钱包之间一键发起全额链上归集划转，轻松升级至最高安全层级。

### 3. 自主托管私钥导出备份
* 私钥完全归您所有，服务器从不触碰。
* 导出流程：前往 **“设置”** > **“钱包与安全”** > **“备份私钥”**。
* 通过生物识别或密码完成鉴权后，复制您的私钥 (`0x...`) 并离线妥善保存。
* 您可以随时将该私钥导入至 MetaMask、Rabby、Rainbow 或 Coinbase Wallet 等任何 Web3 钱包。

## 12. 🔒 全球合规隐私保护与账户彻底注销

CofreAdmin 严格遵守国际通用数据主权法规（包括 GDPR、巴西 LGPD 以及 CCPA）：

### 账户与数据永久注销机制：
1. 打开 **“设置”** 并滚动至页面最底部。
2. 在 **“隐私与数据”** 栏目下，点击 **“注销我的账户与数据”**。
3. **注销执行流程说明：**
   * **云端数据物理粉碎：** 数据库中与您账号关联的 `userData` 业务流水与配置信息将被永久彻底抹除。
   * **设备沙盒全量清理：** 浏览器本地存储 (`localStorage`、缓存及会话数据) 将被全量清空。
   * **合规存证留痕：** 依据国际法规合规要求（如巴西 LGPD 第 16 条及欧洲 GDPR 第 17 条免责条款），系统将自动归档一份不可篡改的匿名化审计存证凭证 (`legalAuditArchive`)，用于证明该数据已依法合规注销。
   * *注意：在注销账户前，请务必先将链上 USDC 提现至外部钱包或妥善备份好私钥。*

## 13. ❓ 常见问题解答 (FAQ)

### 为什么选择 Base 网络，它有什么优势？
Base 是 Coinbase 孵化的以太坊第二层扩容方案 (Layer 2)。它将多笔交易打包压缩后上链验证，在继承以太坊顶级去中心化安全性的同时，将转账成本压缩至微美分级别，出块速度快至约 2 秒。

### 跨服务商账号统一机制是如何运作的？
如果您此前使用 Google 登录，后续使用 Discord 并携带相同的已验证邮箱登录，CofreAdmin 会自动关联同一合法身份，保留相同的链上钱包地址与数据，无需二次签署协议或创建分裂账户。

### 快速隐私模式有什么作用？
轻触余额旁的眼睛图标，即可将主页所有涉及具体金钱的数值替换为掩码 (`••••`)，防止在公共交通工具或公共空间被旁人窥视。

### 是否支持向 Basenames 或 ENS 域名转账？
完全支持！在发送界面中输入任何 `.base.eth` 或 `.eth` 域名，系统将自动解析链上对应地址并进行安全防欺诈核对。

### 转账 USDC 时真的不需要 ETH 吗？
是的。通过 EIP-3009 赞助机制，系统已完全抽象掉 Gas 费，微小手续费直接从转账的 USDC 零钱中扣除。

### 谁能冻结或挪用我的资金？
没有任何人可以。CofreAdmin 属于完全自主托管架构，私钥仅掌握在您个人手中，任何开发者、服务器或第三方均无权干预或冻结您的资金。
