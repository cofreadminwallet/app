## 1. 项目概览与市场契机 (Pitch)

### 痛点与挑战
在拉丁美洲和全球新兴市场中，本国法币持续贬值、高通货膨胀以及传统银行高额的手续费，不断侵蚀着普通大众的储蓄财富。获取稳定硬通货（如美元）受到高门槛起存额、复杂外汇审批以及收费高达 5% 至 12% 的跨国汇款渠道的重重阻碍。

与此同时，传统 Web3 应用给大众用户带来了难以逾越的技术鸿沟：
* **Gas 代币摩擦:** 强迫非技术用户购买、持有并计算易波动的底层原生代币（如 ETH），仅仅为了发送一笔基础稳定币转账。
* **助记词保管门槛:** 12 或 24 个单词的助记词极易丢失或记录错误，一旦失误将造成资产永久无法追回。
* **令人望而生畏的界面:** 充斥着未格式化的十六进制长地址、滑点设置以及复杂的 Gas 参数。
* **链上地址投毒攻击 (Address Poisoning):** 恶意攻击者生成具有相同前缀与后缀的虚假地址，诱导用户在剪贴板粘贴时发生误转账。

### 解决方案: CofreAdmin Wallet
**CofreAdmin** 打造了专为新兴市场设计的**自托管 Web3 个人财务操作系统**，以超轻量、极速响应的渐进式 Web 应用 (PWA) 呈现。它将现代数字银行日常使用的直观便捷性与去中心化金融的资产主权和不可篡改的加密安全性深度结合。

应用深度扎根于 **Base L2 (Coinbase)** 生态，并采用 **Circle 原生 USDC** 进行底层资金结算，让普通大众、自由职业者与中小商户能够以近乎为零的 Gas 成本和秒级到账速度完成储蓄、分类记账、付款和收款。

## 2. 底层网络与代币基础 (Base L2 与原生 USDC)

| 生态要素 | 实现细节 | 用户与协议收益 |
| :--- | :--- | :--- |
| **Layer-2 Rollup** | **Base L2** (`Chain ID: 8453`) | 基于 Optimism OP Stack 构建，以太坊主网级安全，亚秒级交易确认与微乎其微的费用（平均 < $0.005 USD）。 |
| **清算资产** | **原生 USDC** (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`) | 由 Circle 直接发行的 100% 储备金审计数字美元，合规透明、流动性充裕，可与美元 1:1 承兑。 |
| **无 ETH Gas 运行** | **EIP-3009** (`transferWithAuthorization`) | 用户仅在本地离线签署授权凭证，中继网络全额代付 Gas，费用直接从转账中清算。 |
| **协议国库地址** | `0xc143C3A4106B3aE36b43D69807fa5D79d92419aF` | 经过硬件多签审计的公开金库，全自动接收协议微费。 |

### 为何选择 Base 与原生 USDC？
* **终端用户零 Gas 波动烦恼:** 通过 EIP-3009 代付方案，用户无需持有任何 ETH，费用在 USDC 流转中自动结算。
* **机构级合规与资金安全:** 与跨链桥合成代币 (Wrapped) 不同，Circle 原生 USDC 拥有公开可查的月度储备证明与破产隔离保护。
* **即时安装体验 (PWA):** 绕过应用商店 30% 抽成与审核限制，无需下载浏览器扩展插件，几秒内即可安装至手机或桌面主屏幕。

```

┌──────────────────────────────┐              ┌──────────────────────────────┐
│       协议转账微费           │              │      法定货币出入金网关      │

│ • 保底费用: $0.05 USD        │              │   0.5%–1.2% 竞争力点差       │
```

1. **链上转账微费 (现已运行):** 发生在 Base L2 上的每笔外部转账均会自动扣除 **0.20%（保底 $0.05 USD）** 汇入协议国库 (`0xc143C3A4106B3aE36b43D69807fa5D79d92419aF`)。该机制保证项目营收与整体链上交易规模呈线性同步增长。
2. **法币入金与兑换点差 (路线图第三阶段):** 通过连接本地实时清算网络（巴西 Pix、墨西哥 SPEI、哥伦比亚 PSE 等），在法币直接兑换自托管 USDC 的流程中赚取点差收益。
3. **企业端与白标金库授权 (远期规划):** 为寻求向终端用户提供美元储蓄金库的新兴市场中小金融机构或合作社提供开箱即用的技术赋能。

## 6. 非托管加密安全模型

CofreAdmin 坚定践行**纯客户端零知识非托管架构 (Zero-Knowledge Client-Side Architecture)**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      浏览器本地纯客户端加密隔离区                           │
├─────────────────────────────────────────────────────────────────────────────┤
│  用户主密码 / 设备硬件生物识别凭证                                          │
│       │                                                                     │
│       ▼                                                                     │
│  PBKDF2 强力密钥派生 (100,000 次哈希迭代, 设备独立动态随机盐, SHA-256)      │
│       │                                                                     │
│       ▼                                                                     │
│  AES-GCM 256 位解密主密钥 (仅短暂留存系统内存，随用随销)                    │
│       │                                                                     │
│       ▼                                                                     │
│  链上真实私钥 (绝不通过网络上传，绝不保存在中心化服务器)                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **私钥零知识完全隔离:** 私钥生成与交易签名完全在本地浏览器环境中由 `crypto.subtle` 原生底层驱动，私钥明文从不离开用户设备内存。
2. **3代加密敏捷演进体系:**
   * **第 1 代 (经典兼容):** 早期本地基础存储。
   * **第 2 代 (PBKDF2 + AES-GCM 256):** 100,000 次哈希派生配合设备物理盐的高强度防护。
   * **第 3 代 (生物识别 Enclave):** 通过 WebAuthn 直接调用设备安全芯片 (Touch ID / Face ID / 硬件 PIN)。
3. **视觉双重校验防投毒机制:** 对目标地址的前 6 位与后 4 位字符进行独立、色彩高对比度的徽章化渲染，彻底粉碎基于剪贴板替换的地址投毒欺诈。
4. **合规性加密销毁档案 (`legalAuditArchive`):** 严格执行 GDPR 第 17 条与巴西 LGPD 第 18 条规范，抹除所有个人可识别信息的同时，生成无法伪造的密码学销毁存证。

## 8. 混合式金融智能架构特别说明

> ### ⚖️ 关于混合式金融智能架构的特别说明
> 在涉及**真实资金、自托管密码学及用户个人财富守护**的金融操作系统中，资金执行必须做到绝对精确、完全确定并具有透明可审计性。
>
> 为此，CofreAdmin 严格推行**混合式系统架构 (Hybrid Architecture)**：
> * **100% 确定性执行层:** 所有的资金转账结算、余额状态校验、EIP-3009 授权凭据签名、非对称密钥派生以及多金库账本划拨，**必须且仅由**确定性算法、明确的业务规则启发式逻辑以及已审计的智能合约严格掌控。
> * **仅限顾问级分析智能层:** 预测模型、消费自动分类启发式规则及资产洞察**仅运行在只读的咨询与辅助建议层面**（例如消费趋势分类、预算使用节奏提醒以及统计报表展示）。
>
> **根本安全原则:** 严禁将直接的资金流转或签名执行权力授予任何概率型智能模型。这种架构层面的严格物理隔离，彻底根除了生成式幻觉、意料之外的交易循环或未经授权划转带来的灾难性风险，全方位确保用户资金资产的绝对安全。

> 💡 **运营与战略说明：**
> * **支付基础设施：** 巴西 Pix 作为核心区域法币至 USDC 出入金引擎。未来将通过合规第三方网关拓展至拉美及全球支付渠道（墨西哥 SPEI、哥伦比亚 PSE、银行卡与电汇）。
> * **动态路线图：** 本路线图为动态规划；阶段里程碑与功能整合将根据市场变化、监管演进以及安全性与用户体验优化灵活调整。
